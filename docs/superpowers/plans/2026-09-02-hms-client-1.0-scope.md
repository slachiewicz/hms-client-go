# hms-client-go 1.0 Scope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the remaining 1.0 capabilities defined in SPEC.md: caller identity over binary NOSASL (`set_ugi`), TLS on the binary socket, catalog-resolution fixes and struct additions, partition lookups by names/filter/values, `AlterDatabase`, metastore notifications, read-only column statistics, minimal ACID locks and transactions, pure-Go Kerberos, observability hooks, and the stability policy artefacts.

**Architecture:** Every capability is a thin addition to the existing shape: bind the generated RPC as a `func` field on `conn`, expose a clean type in `types.go`, convert in `convert.go`, route through `c.call`/`c.read`, emulate in `internal/hmstest`, and extend `test/integration_test.go` so the nightly matrix covers it on real servers. Transport work (set_ugi, TLS, Kerberos) lives in `internal/transport` and `conn.go`.

**Tech Stack:** Go 1.26, `github.com/apache/thrift v0.24.0`, testify; **one new dependency** approved for Task 9 only: `github.com/jcmturner/gokrb5/v8`.

**Spec:** `SPEC.md` (§3.1 auth and TLS, §4.2, §5.0–§5.10, §7, §8, Appendix A). Layout and slice notes: `PLAN.md` Slices 7–15. Repo rules: `AGENTS.md`.

## Global Constraints

- Everything in the previous plan's Global Constraints still binds: package `hms` at the root; no generated type in exported identifiers; the generated client is never stored in an interface-reachable field (bind `func` fields on `conn`); every network call honours ctx; `catName` never written to a server without catalog support; fallbacks keyed on `UNKNOWN_METHOD` and cached per connection; every error matches exactly one sentinel; tests in `_test` packages, table-driven, `t.Parallel()` everywhere; fixture-based wire tests; `make check` green before every commit; commit messages without session URLs or AI trailers.
- Request structs are always built with the generated `NewXxx()` constructors so Thrift defaults go on the wire (Appendix A, last row). The fixture rejects non-default `Engine`/`ID`/`WriteId` and the white-box `requests_internal_test.go` round-trip test must gain a row for every new request type.
- Idempotent reads use `c.read`, everything else `c.call` (SPEC §4.2). Op strings are Thrift wire names.
- New RPCs must exist in `idl/hive_metastore.thrift` (Hive 4.2.1) and be checked against SPEC §2.1 for 2.3/3.x availability; where a request-variant is 4.x-only, use `cn.tryReq` with the legacy form.
- Each task extends `test/integration_test.go` with at least one assertion that runs on every matrix version it applies to, and the fixture (`internal/hmstest`) with the handler(s) the client needs, honouring per-version RPC availability.
- No new dependency except `gokrb5` in Task 9.

### Task 3: Catalog resolution fixes, struct additions, and round-trip fidelity

**Peer gaps folded in (from polytable's migration audit):**
- **G3, round-trip fidelity (most important).** `tableToThrift`/`partitionToThrift` start from `NewTable()`/`NewPartition()` and copy only modelled fields, so `GetTable` → `AlterTable` on a table Spark or Trino registered silently resets `OwnerType`, `WriteId`, `Privileges`, `SkewedInfo` locations, `Temporary`, `RewriteEnabled`, `CreationMetadata`, `Id`, `TxnId`, `AccessType` and the capability fields. Fix: `hms.Table` and `hms.Partition` gain an unexported `raw *hive_metastore.Table` / `raw *hive_metastore.Partition` set by the `FromThrift` converters (a deep copy via the generated struct's own `Write`/`Read` through a `thrift.TSerializer`, or field-wise copy; pick one and say why). `tableToThrift`/`partitionToThrift` start from a copy of `raw` when present and overwrite only the modelled fields; when absent they start from `NewXxx()` as today. This is allowed by AGENTS.md invariant 4 (the field is unexported). Tests: white-box round trip proving every unmodelled field survives `tableFromThrift` → `tableToThrift`; a black-box test that `GetTable` then `AlterTable` on the Hive40 fixture preserves a seeded `Privileges`/`RewriteEnabled`/`Id`; document in SPEC §5.4 as "Round-trip fidelity".
- **G2, clean messages.** Add `func Message(err error) string` returning the server-side exception message (`Message` field of the generated exception, or the transport error text) without the Go struct dump, and make `hmsError.Error()` use it: `"<op>: <message>"`. Keep `errors.As` to the generated exception working. Tests in `errors_test.go`; SPEC §7 note.
- **G7.** Export `WithChunkSize(n int) Option` (rename the unexported one; keep the clamp) and document in SPEC §5.1.
- **G6, builder alignment.** Align `formats.go` with the conventions xtable-hive-metastore's Java builders write, since that is what polytable ports and what Spark/Trino expect: Delta uses `storage_handler = io.delta.hive.DeltaStorageHandler`, SerDe `org.apache.hadoop.hive.serde2.lazy.LazySimpleSerDe` with `serialization.format = 1` and `path = <location>` SerDe parameters, no input/output format; Hudi output format `org.apache.hadoop.hive.ql.io.parquet.MapredParquetOutputFormat`, input `org.apache.hudi.hadoop.HoodieParquetInputFormat`, SerDe `ParquetHiveSerDe` with `path` parameter, table parameter `hudi.metadata-listing-enabled` left to the caller; Iceberg adds `iceberg.catalog = location_based_table`. Update SPEC §6 and `formats_test.go` literals to match and cite the source (`xtable-hive-metastore` builders) in SPEC §6.


**Files:** `types.go` (`Table.OwnerType PrincipalType`, `Database.CreateTime time.Time`, `SkewedInfo{ColumnNames []string; ColumnValues [][]string}` on `StorageDescriptor.Skewed *SkewedInfo`), `convert.go` (round-trip the three; `Skewed.Locations` deliberately absent, comment referencing SPEC §1.1), `table.go` (`AlterTable` honours `newTable.CatalogName` per SPEC §5.0 with the same precedence helper `CreateTable` uses; factor `resolveCatFor(ctx, cn, structCat string, opts)`), `client.go` (`CreateDatabase`/`AlterDatabase` share it), tests: `table_test.go` (AlterTable with `newTable.CatalogName="spark"` on Hive40 records catName "spark"; `InCatalog` still wins), `convert_internal_test.go` (OwnerType/CreateTime/Skewed round trip), integration `TestTables_...` asserts `OwnerType == PrincipalUser` after create and that a skewed table's names/values survive (create with `Skewed` set on 4.x; on 2.3/3.x too since the fields are old).
